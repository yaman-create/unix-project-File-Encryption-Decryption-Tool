# unix-project-File-Encryption-Decryption-Tool
A simple menu-driven **File Encryption & Decryption utility** built using **Bash Shell Script**.  
This tool uses **XOR Cipher logic** to encrypt and decrypt files and demonstrates handling file streams, loops, hex processing, and UNIX utilities like `xxd`.



---

## ✨ Features

- Encrypt any file using a password key
- Decrypt encrypted files back to original
- Menu-driven interface
- Uses basic cryptography logic (XOR)
- No external complex libraries — uses UNIX command `xxd`
- Lightweight and portable

---

## 🛠️ Requirements

| Requirement | Description |
|------------|-------------|
| OS         | Linux / Unix / MacOS |
| Shell      | bash |
| Tools Used | `xxd` command (installed by default in most systems) |

---

## ▶️ How to Run

### **1️⃣ Give execute permission**

chmod +x crypto.sh
./crypto.sh
